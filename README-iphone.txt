MyUIS для iPhone (веб-додаток)

ОДИН РАЗ (на компьютере):
1. github.com -> "+" -> New repository. Имя: myuis-iphone. ВАЖНО: выберите Public (в приватном GitHub Pages бесплатно не работает). Create repository.
   В репозитории нет ничего секретного: ссылку с токеном вы вводите только на своём телефоне.
2. "uploading an existing file" -> перетащите ВСЕ файлы из этой папки (index.html, app.js, style.css, sw.js,
   manifest.webmanifest, logo.svg, icon-180.png, icon-192.png, icon-512.png) -> Commit changes.
3. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, папка / (root) -> Save.
4. Через 1-2 минуты вверху страницы Pages появится адрес: https://ВАШ-ЛОГИН.github.io/myuis-iphone/

НА iPHONE:
1. Откройте этот адрес в Safari (именно Safari).
2. Кнопка "Поделиться" -> "На экран «Домой»" -> Добавить.
3. Запускайте MyUIS с домашнего экрана. При первом запуске вставьте ссылку на данные
   (https://script.google.com/.../exec?token=...) - ту же, что в приложении для ПК.
